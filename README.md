#Smart Expense Tracker
This is a simple expense tracker I made using JavaScript. It helps me keep track of my expenses and see how much of my monthly budget I have spent.
Features
•	Add new expenses with a title, amount, category, and date.
•	View all recorded expenses.
•	Calculate total spending.
•	Check how much money is left in the budget.
•	See how much money is spent in a specific category.
•	Search for an expense by its title.
•	Filter expenses by category.
•	Get a warning when spending reaches 80% of the budget or goes over the budget.
Technologies Used
•	JavaScript
How to Run
1.	Download or clone this repository.
2.	Open the JavaScript code in a browser environment.
3.	Run the code in the browser console.
4.	Follow the menu and enter the number for the feature you want to use.
What I Learned
While making this project, I practiced using JavaScript variables, arrays, objects, functions, loops, and conditional statements. I also learned how to use array methods like find(), filter(), and reduce().
